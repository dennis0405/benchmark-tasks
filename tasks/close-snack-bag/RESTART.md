# Restarting on a new GPU machine

This is a handoff for the **pre-Dream-1** work. The recorded task and YAM
demo use the PhysX rigid-packet approximation in `arena_scene.py`. The
Newton deformable, gas and breakable-chip experiments remain separate probes;
they are not the submitted scene or its scorer. See `README.md` and
`ITERATION_NOTES.md` for results and limitations.

## Preserved and external data

- This branch contains the task, USD assets, scripted YAM controller, scorer,
  tests, final three-camera H.264 rollout, setup image and physical-control
  results in `evidence/flat-chip-demo/`.
- `evidence/iteration-nov12/clip-followup/raw-v16/` and `raw-v18/` contain
  selected deformable packet node snapshots and results. Their support/film
  intersection reports are adjacent as `v16-fixture-intersections.json` and
  `v18-fixture-intersections.json`; both controls failed.
- Other trial outputs under the original VM's `/data/snack-runs/` were not all
  in Git. They included intermediate logs and surface snapshots; the directory
  occupied about 123 MB when checked. The user later reported deleting the
  Brev instance. An independent backup of those extra outputs is not known;
  do not assume they are recoverable.
- No virtual environment, Isaac Sim installation, GPU driver, authentication
  token or Dream-1 run is stored in this repository.

## Fresh setup

Follow the [RoboCurve walkthrough](https://tasks.robocurve.org/walkthrough)
and the pinned YAM checkout's `README.md` and `setup.sh`. The following is a
starting procedure for **new, empty paths**, not a tested fresh installation.
`setup.sh` downloads and installs substantial software, accepts the Isaac Sim
EULA through its generated environment file, and its unpinned dependencies
can change. Review the script and current license terms on the new machine.

```bash
git clone https://github.com/dennis0405/benchmark-tasks.git
cd benchmark-tasks
git switch feature/close-snack-bag
export SNACK_TASK_DIR="$PWD/tasks/close-snack-bag"

export ARENA_DIR="$HOME/robocurve-env/IsaacLab-Arena"
mkdir -p "$HOME/robocurve-env"
git clone https://github.com/kairosiann/yam-isaac-lab-arena.git "$HOME/robocurve-env/yam-isaac-lab-arena"
git -C "$HOME/robocurve-env/yam-isaac-lab-arena" checkout --detach 0059d02a1a91bc6834c1d0846022891df0c78730
git clone --branch release/0.3.1 https://github.com/isaac-sim/IsaacLab-Arena.git "$ARENA_DIR"
git -C "$ARENA_DIR" rev-parse HEAD
```

The last command must print `c7edf3a9d5d8276565208f72422f8f8a0806d6cf` for
the recorded Arena revision. If the release branch has moved, stop and
reconcile it before installing; the setup script expects the checkout to be
on the branch `release/0.3.1` rather than a detached commit.

```bash
cd "$HOME/robocurve-env/yam-isaac-lab-arena"
export DREAM_SPEC='git+https://github.com/kairosiann/inspect-robots-dream@b5e936a201cec66c54c297e522c920d98445e339'
./setup.sh
source "$ARENA_DIR/yam.env"
git -C "$ARENA_DIR" apply --check "$SNACK_TASK_DIR/environment/arena-production-assets.patch"
git -C "$ARENA_DIR" apply "$SNACK_TASK_DIR/environment/arena-production-assets.patch"
```

The patch reproduces the original machine's asset-path modification. If it
does not apply cleanly, inspect the checkout and asset configuration instead
of forcing it. It does not bundle remotely served Arena assets. Verify that
the package versions and submodule commit above match after installation;
install Open3D separately if running the deformable intersection checks and
the setup did not install it (`uv pip install --python "$ARENA_DIR/.venv/bin/python" 'open3d==0.19.0'`);
check the resolved versions again afterwards. Changes in packages, assets,
driver or hardware can alter the results. First-time asset downloads also
require network access.

## Reproduce the current scene

Use a new output directory. These commands run a fixed layout, not a multi-seed
evaluation. The demo took 74.4 s before encoding on the recorded machine.

```bash
source "$ARENA_DIR/yam.env"
cd "$SNACK_TASK_DIR"
python -m unittest -v test_scoring
python demo_robot.py "$HOME/snack-runs/demo" --record --cam-width 640 --cam-height 352
python validate_physics.py "$HOME/snack-runs/physical-controls.json"
```

Create `$HOME/snack-runs` before the control command if needed. The demo
writes `result.json` and videos for all three cameras. The recorded run reached
1.0 in 403 steps; compare the new result and visual motion rather than assuming
the same score. Placement controls intentionally initialize objects and are
not robot demonstrations. The exact source/asset hashes used by the recorded
rollout are in `evidence/flat-chip-demo/result.json`.

To inspect a saved failed deformable trial without modifying tracked evidence:

```bash
cp -R evidence/iteration-nov12/clip-followup/raw-v16 /tmp/snack-raw-v16
python check_fixture_intersections.py /tmp/snack-raw-v16
```
