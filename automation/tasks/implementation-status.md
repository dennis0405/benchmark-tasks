## 첫 파일럿 전 인증

- 로컬 Brev·GitHub와 원격 Codex 인증은 확인했다.
- 팀 토큰과 Dream 키는 사용자가 `rcauto auth`에서 직접 입력한다. 현재 미등록이다.
- 실제 Dream 비용은 미검증이므로 불명 비용의 예약을 자동으로 풀지 않는다.
