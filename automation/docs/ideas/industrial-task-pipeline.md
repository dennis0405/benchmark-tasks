# 산업 근거를 바탕으로 한 단일 태스크 자동 제작

상태: 방향과 MVP 범위는 사용자 확정. 상세 운영 방식은 설계 검토 초안.
기준일: 2026-11-13 (Asia/Seoul). 구현은 시작하지 않았다.

## 해결할 문제

실제 로봇 제작·데이터센터 작업의 자동화 가치를 유지하면서, 중복과 환경·채점
결함을 일찍 걸러 사람이 제출 직전의 결과만 검토하도록 만들 수 있을까?

## 선택한 방향

산업 자료에서 여러 후보를 만들고, 산업적 의미·차별성·조작 난도·물리 재현·측정 가능성을
검토해 하나를 제작한다. 어려워 보이는 이야기를 발명하지 않고, 실제 작업
절차와 장비에서 목적을 도출한다. 극단적인 난도는 필수 조건이 아니지만
가능하면 조작 자체가 어려운 후보를 우선한다. 수행 방법을 알려줘도 남는
정렬·접촉·힘 조절·파지 전환·양팔 협응 등의 난도와, 기존 과제와 구분되는
물리적 능력 및 자동화 가치를 설명할 수 있어야 한다.

산업 자료 조사와 함께 공개 장비 에셋도 발굴·확보한다. 실제 장비·작업 근거와
대응하는 CAD·메시·URDF·USD를 연결해 재사용 가능성과 수정 비용을 후보 선별에
반영한다. 에셋이 있다는 이유만으로 작업의 중요성이나 물리적 타당성을 인정하지 않는다.

환경이 준비된 뒤 데모를 개발한다. 환경 준비 여부와 데모의 성공 여부는
분리한다. 데모와 채점이 검증된 후 Dream 최종 평가를 한 번 실행하고,
중복을 재검사해 보고한다. 사용자가 승인한 결과물만 제출한다.

## 검증할 핵심 가정

- [ ] 출처를 확보한 후보가 신규성과 제작 가능성을 함께 만족한다.
  — 후보 탈락 이유와 뒤늦게 발견한 문제를 비교한다.
- [ ] 실제 장비의 형태와 핵심 상호작용을 Brev의 선택한 실행 환경에서 재현한다.
  — 에셋·관절·접촉·로봇 작업 공간을 데모 전에 시험한다.
- [ ] 환경 준비 기준이 후반부 재작업을 줄인다.
  — 데모 시작 후 환경을 다시 수정한 이유와 횟수를 기록한다.
- [ ] 자동 채점이 실제 성공과 파손·편법을 구분한다.
  — 정상 성공·무행동·미완료·관련 실패 대조군을 검사한다.
- [ ] 사람이 영상·명세·검증 보고서로 제출 여부를 판단할 수 있다.
  — 보고서만으로 판단할 수 없었던 정보를 기록한다.

## 확정한 MVP 범위

산업 근거 조사, 여러 후보 선별, 두 차례 중복 검사, 단일 태스크 환경 제작·검증,
데모·채점 검증, 최종 Dream 평가 1회, 사용자 보고·승인, 승인 후 제출과 접수 확인.
강체를 기본으로 하며 기존에 필요한 동작이 구현된 연성 에셋도 검증 후 허용한다.
새 에셋 제작은 허용한다. 제작 과정과 외부 제출 상태를 보존해 중단 후 이어간다.

첫 검증은 실제 태스크 한 건의 전체 흐름과 복구 동작이다. 하루 1개는 운영 목표이며
기한을 맞추기 위한 품질 기준 완화나 자체 판정만으로 대회 채택을 주장하지 않는다.

## 첫 MVP에서 제외

- 여러 태스크 동시 제작: 한 태스크의 전 과정을 먼저 안정화한다.
- 새로운 연성 물리 모델 연구: 제작 성공 여부가 별도 연구에 종속되는 일을 줄인다.
- 승인 없는 제출과 자동 Dream 재평가: 확정한 개입·평가 원칙을 지킨다.
- 단순 파라미터 변형의 대량 생산: 목적과 물리 기술의 차별성이 필요하다.
- 특정 에이전트·DB·대시보드의 선결정: 운영 계약을 먼저 검토한다.
